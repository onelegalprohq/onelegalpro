- **PF-023 — Git Hooks.** Added tracked, reviewable native Git hooks under `.githooks/` (`pre-commit`, `commit-msg`, `pre-push`, plus `install.sh`/`status.sh`/`uninstall.sh` and a shared `lib/common.sh` helper) — POSIX `sh`, no new Composer/npm dependency, no CaptainHook/Husky/Lefthook. `pre-commit` runs `git diff --cached --check` plus check-only `composer pint:test`; `commit-msg` validates Conventional Commit subjects (with Merge/Revert/fixup!/squash! exemptions); `pre-push` runs blocking `composer phpstan` and `composer test` (SQLite `:memory:` per `phpunit.xml`, no PostgreSQL dependency). Hooks are never installed automatically by Composer or Docker lifecycle events — installation is an intentional, separate developer action, and remains bypassable with `--no-verify`.
